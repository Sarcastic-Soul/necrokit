# Kiroween Submission Checklist

## Form selections

- Category: **Skeleton Crew**
- Bonus: **Best Student Project: Skeleton Crew**
- Bonus: **Best Kiro Crew App**
- Bonus: **Social Blitz Prize**
- Bonus: **Bonus Blog Prize**
- Do not select Startup or Ghost of Kiroween Past.
- Overall and Best Demo are automatic considerations.

## Main repository field

Use the public GitHub URL for `necrokit`. It must contain:

- both app folders
- shared core package
- root `.kiro` directory
- visible open-source license
- setup and test instructions
- fixture data and demo path

## Crew repository field

Use the public GitHub URL for `necrokit-crew`. It must be a separate repository and newly created during the submission period. Describe Undertaker's features and functionality.

## Required submission assets

- Working hosted demo or test build.
- Public YouTube video under three minutes.
- English project description.
- Kiro usage write-up covering specs, steering, hooks, MCP, PBT, and powers actually used.
- Student LinkedIn profile.
- Student email.
- Current year and degree.
- Recognized institution name.
- Test instructions if the deployed demo needs them.
- Social post URL. The post must start with `#KiroweenHackathon26`.
- Public blog URL. The post must mention that it is written as part of Kiroween 2026 and be published during the submission period.

## Final compliance checks

- Project was created during the submission period.
- No secrets are committed.
- `.kiro` is not ignored.
- GitHub account owns both public repositories.
- All third-party licenses and APIs are disclosed.
- Demo behavior matches the submitted text.
- Submission is saved and submitted before the official deadline.
