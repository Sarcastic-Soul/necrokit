# Fixtures

All fixtures in this folder are synthetic. The repository names (`acme/*`), dates, and counts are invented for demo and test use. They do not describe any real project.

- `active.json`: healthy repository, recent release, passing CI, licensed.
- `neglected.json`: stale issues, old pull requests, failing CI, no release in over a year.
- `archived.json`: archived repository with no license and no recent release.
