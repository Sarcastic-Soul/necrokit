# Repo Reaper requirements

1. A user can enter a public GitHub repository URL or load a fixture.
2. The application displays repository maintenance findings with evidence.
3. The application checks commits, releases, issues, pull requests, CI, and license signals when available.
4. The application displays an explainable score and severity breakdown.
5. The application generates a prioritized maintenance or revival plan.
6. The fixture path works without network access or API keys.
7. Live calls fail safely and display an actionable unavailable state.
