# NecroKit project steering

- Build two distinct applications from one stable shared core.
- Prefer deterministic evidence and named rules over opaque AI claims.
- Every finding must include evidence, an unavailable reason, or a fixture citation.
- Never call an external API without timeout, rate-limit handling, and fixture fallback.
- Never require a secret or paid service for the judging path.
- Do not delete or weaken tests to make a result green.
- Keep UI copy plain, accessible, and understandable in a ten-second demo.
- Keep package-specific and repository-specific logic outside `packages/necrokit-core`.
